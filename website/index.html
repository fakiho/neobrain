Capabilities

A mind, not a log.
Every organ accounted for.

Atoms, hubs and typed edges in local SQLite. Deterministic rank. Dreams that consolidate. A soul authored by the agent itself.

Durable memory

Atoms, hubs and typed edges in local SQLite — each carrying an id, links and provenance. A mind model rather than an append-only log.

Hybrid recall

Lexical match blended with local cosine vectors. Returns the top-K active memories by relevance score within a token budget — never the whole store.

Nightly dreams

Light, REM and deep replay consolidates top-ranked atoms into summaries and associations, then writes the first-person DREAMS.md diary.

Self-authored soul

IDENTITY.md and SOUL.md are written only by the agent's own reflect and dream phases, from its own experience. Safety red lines stay immutable.

Life loop

An in-process state machine: perceive → reflect → act → rest. Cadence lives in code and the database — not in OS timers.

Deterministic context injection

Standing directives, per-turn recall, compaction hooks and injection logging are pushed by the OpenCode plugin lanes — no model tool choice required.

Local-first by default

Embeddings run on a local Ollama model, so memory never leaves the host. The brain's own cognition uses a BYOK OpenAI-compatible endpoint.

Ingest adapters

The perceive phase reads OpenCode sessions, git repositories and workspace docs — or ingest a one-shot payload with neobrain ingest.

The Mind Model

Forgetting is an economy,
not a deletion.

Rank decides what surfaces. It is fully deterministic, and the model never gets a vote.

Rank, computed in the open

Three bounded factors, multiplied. Floors keep age and graph isolation from being fatal on their own — but feedback is the only factor that can reach zero, so a flood of noise forgets even a fresh, well-connected memory.

# deterministic — no model discretion
quality = clamp01( feedback · decay · conn )
decay   = floor + (1−floor) · recency
conn    = floor + (1−floor) · connectivity
# exposure (served + 3·interacted) never raises quality
feedbackthe only zero
decayrecency
connconnectivity

Rank states — and what they mean

A low-quality atom is never deleted. It changes state, cheaply and reversibly. A later useful or used rating promotes it back.

active

High rank. Eligible for recall and served when relevant within the token budget.

ignored

Low rank, low exposure. Never surfaced. Zero cost. Never deleted.

archived

Low rank, high exposure. Unretrievable but recoverable — archive ≠ delete.

Dreams consolidate, but they never decide retention. Only rank does. Manual removal is the explicit neobrain forget override.

Quickstart

Three commands.
A mind that keeps living.

Install from a checkout of the repo. The daemon owns the life loop and serves both the JSON API and the built Observatory.

1

Create the store

neobrain init builds the SQLite store and prints the next steps. Add --install-plugin to symlink the OpenCode adapter in one go.

2

Start the daemon

neobrain start runs the API, the dashboard and the in-process life loop: perceive, reflect, act, rest.

3

Open the Observatory

neobrain ui opens the dashboard at 127.0.0.1:9192 — brain graph, dreams, memory, identity, infra and the live debug trace.

The plugin lanes inject themselves. Once the adapter is symlinked into your OpenCode plugins directory, the wake-up pack, persona docs, standing directives, per-turn recall, the unrated-feedback protocol and the compaction hook all fire automatically. You do not wire them per request — you just watch the injections land on the Debug view.
