# neoBrain

A simulated brain for AI agents: durable memory, rank-based forgetting,
nightly dreams and a self-authored soul — one local daemon, one dashboard.

```bash
npm install -g neobrain   # (public packaging, sprint S8)
neobrain init             # detect opencode, install plugin, generate persona, init DB
neobrain start            # daemon: life loop + API + dashboard
neobrain ui               # open the Observatory
```

Spec: [`SPEC.md`](./SPEC.md) — the frozen contract. Family: [alionix](https://alionix.com)
· neohive (agents collaborate) + neoBrain (agents remember).
